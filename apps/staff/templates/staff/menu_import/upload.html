How it works

  • Nothing is saved until you confirm the preview. Any error in the file means nothing is saved.
  • Imports add and update — they never delete. To hide something, set its active / available column to no.
  • A row that matches an existing record (by slug, or by name) updates it. Blank cells keep the existing value; to clear a cell, enter a single -.
  • Yes/no columns take yes, no, true, false, 1 or 0. Prices are plain numbers (12.50, no $). Dates are month/day/year: 9/18/2027 (with a time: 9/18/2027 20:00). Times: 20:00.
  • Choice columns take the code or the label (default_food or “Default Food Menu”). Unknown columns are an error, to catch typos.
  • Images aren't in the CSV — set them on each item's Images page.
  • “Export what's loaded now” downloads the current data in these same columns, ready to edit and import again.
