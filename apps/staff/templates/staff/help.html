Getting around the portal

The menu on the left groups pages into Operations (day-to-day running of the site){% if staff_is_manager %}, Content (photos, newsletter, popups, reviews and inquiries){% endif %} and Tools. On a phone, tap ☰ at the top to open it. Sign out is at the bottom of the menu.

What you can do

  • Staff can view the dashboard, menu mode, events and menu items.
  • Managers can also make changes and use the Content pages.
  • Site administrators can also change site settings.

Menu mode (full vs. limited menu)

On busy event days the website shows a shorter limited menu instead of the full menu. The Menu Mode page shows which one is live right now.

  • Automatic (normal setting) — follows the events calendar. The limited menu starts a set number of hours (usually 2) before an event's start time, or all day if the event has no time. Only events with Limited menu ticked count.
  • Force Full Menu — always show the full menu, e.g. if a game is cancelled.
  • Force Game Day Mode — show the limited menu now, e.g. for an unexpected rush.
{% if staff_is_manager %}

Click an option to switch. Remember to switch back to Automatic afterwards — a forced mode stays on until someone changes it.

{% else %}

Managers can change the menu mode.

{# ── Events ─────────────────────────────────────────────────────────────── #}

Events calendar

Games, private parties, live music and holidays. Events control when the limited menu is used (see Menu mode) and appear on the public events calendar.

{% if staff_is_manager %}

Add an event

  1. Events → + Add Event.
  2. Choose the date and type. For games, pick the team and home or away.
  3. Add a start time if there is one — the limited menu starts a couple of hours before it. Leave it blank for all day.
  4. Label is optional — it replaces the default name (e.g. “Steelers vs. Ravens”).
  5. Save.

Home games get the limited menu automatically; away games don't. To use the limited menu for an away game (say, a watch party), edit the event after saving and tick Limited menu. Untick it for events that keep full service, such as most live music.

Change or remove an event

  • Edit — change any detail.
  • Deactivate — hide the event and stop it affecting the menu, without deleting it. Activate brings it back.
  • Delete — remove it for good.
{% else %}

You can see upcoming and recent events. Managers can add, change and remove them.

Menu items and photos

Every dish and drink on any menu. Search by name, or filter by availability and flags (featured, new, chef's special, seasonal).

{% if staff_is_manager %}

Choose an item's photos

  1. Make sure the photo is in the media library first.
  2. Menu Items → find the item → Images.
  3. In each row pick a photo and an order number. Select Primary for the item's main photo.
  4. To remove a photo from the item, tick Delete on its row. (The photo stays in the media library.)
  5. Save.
{% endif %}

Menu names, prices and descriptions are changed by a site administrator.

{% if 'inquiries' in visible %} {# ── Inquiries ──────────────────────────────────────────────────────────── #}

Event inquiries

Requests from the website's private-event form. Each new inquiry is also emailed to the restaurant's notification address, and the customer automatically gets a “we received your inquiry” email.

  • Use the status menu on each row to track progress: New → Contacted once you've reached out → Closed when it's booked or declined.
  • Filter by status at the top to see only what still needs attention.
  • Delete removes an inquiry for good.

Customers say whether they prefer a call or an email — check before reaching out.

Spam

Submissions that look automated — sent within seconds of the page loading, containing web links, or mostly in another alphabet — are filed under Spam (top right) instead of New, and no emails are sent for them. Each shows why it was flagged.

  • Glance at Spam now and then. If a real customer ended up there, change its status to New and contact them yourself — they did not get a confirmation email.
  • Delete spam whenever you like; it doesn't affect anything else.
  • If an unusual flood of inquiries arrives, the site keeps saving them but pauses inquiry emails for the rest of the hour, and emails you a warning.

Media library (photos)

Every photo on the site lives here. The public Gallery page shows only published photos.

Upload a photo

  1. Media Library → + Upload.
  2. Choose the file and give it a name you'll recognise (e.g. “Burger close-up summer”).
  3. Pick a category — it decides which gallery tab the photo appears under.
  4. Add alt text: a short description of the photo for visitors who use screen readers.
  5. The caption is shown to visitors when they open the photo.
  6. Tick Published to show it in the gallery straight away, or leave it hidden and publish later.

Lots of photos at once

Copy the files to the server's media/gallery/ folder (ask your site administrator how), then click Import from Disk. Imported photos start hidden, named after their file names.

Publish, edit, delete

  • Show / Hide on each photo publishes it to the gallery or takes it down.
  • Edit changes the name, category, alt text, caption and display order.
  • Delete removes the photo from the library. The file is kept in a deleted folder on the server, so an administrator can recover it.
  • A photo used elsewhere (a banner, popup or menu item) can't be deleted — the message tells you where it's used. Remove it there first.

Newsletter

Emails to everyone who signed up on the website and confirmed their address. Each email includes an unsubscribe link automatically.

Write and send

  1. Newsletter → + Compose. Enter a subject and write the message — you can add headings, lists, links and images.
  2. Save. This creates a draft; nothing is sent yet.
  3. Check the preview. Use Edit to make changes.
  4. When it's right, click Send Now and confirm. The message says how many people it went to.
  • Sending can't be undone. Clicking Send Now twice won't send it twice.
  • If sending fails completely (for example the mail server is down), the newsletter stays a draft — try again later.
  • Duplicate starts a new draft from an earlier newsletter.
  • Drafts can be deleted; sent newsletters are kept as a record.

Site popups

A message box that appears a few seconds after a visitor arrives — for an announcement, a special, or newsletter signups.

  1. Popups → + New Popup. The title is just for you; visitors see the heading and body.
  2. Either add a button (label and link), or tick Show email signup form to collect newsletter signups instead.
  3. Choose colors and how many seconds to wait before it appears.
  4. Save, then click Activate in the list.
  • Only one popup is live at a time — activating one switches off the others.
  • A visitor who closes the popup won't see it again until their next visit. People who have already subscribed never see it.
  • Deactivate it when the promotion ends.

Reviews

Customer reviews shown on the website's Reviews page and homepage.

  • Import Google / Import Yelp fetch the latest reviews (Google sends up to 5, Yelp up to 3). Reviews already imported are skipped.
  • Imported reviews arrive Hidden. Click the Hidden button to make a review Active on the Reviews page (click again to hide it).
  • ☆ Feature a review to put it on the homepage — the first three featured reviews are shown.
  • Delete removes a review for good.

{% if 'settings' in visible %} {# ── Settings ───────────────────────────────────────────────────────────── #}

Site settings and color schemes

Administrators only. Changes take effect on the site immediately.

  • Internal notification email — where inquiry and contact-form alerts go. Not shown on the site.
  • Public contact email and phone — shown on the site and in the footer.
  • Reservations URL — the link on the homepage reservation bar.

Color schemes

Named sets of colors used by promo menus and popups. Editing a scheme restyles everything that uses it. Only one scheme can be the default (used when nothing else is chosen) — marking a new one as default unmarks the old one.

Everything else (banners, page text, menus, staff accounts) is managed in Django Admin, linked under Tools. To make someone a manager, open their user in Django Admin and add the Staff Manager group.
